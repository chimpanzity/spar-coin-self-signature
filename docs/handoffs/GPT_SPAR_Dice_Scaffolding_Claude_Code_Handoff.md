# SPAR Track 1 · Dice forecast scaffolding
## Claude Code implementation and run handoff

**Research question.** Suppose Qwen forecasts the rolls of “a blue shape” more accurately than those of “an orange shape.” Does *blue* bring the forecast closer to Qwen’s own next-face probabilities? Does it help Qwen more than it helps predict Mistral? Could we have predicted the direction of this effect from Qwen’s associations with the two words in an entirely separate task?

**Primary dependent variable.** For a given forecaster, wording and preceding roll history, record the vector of **six next-face log-probabilities**. Keep both the raw vocabulary log-probabilities and their face-normalized version. The **primary scalar outcome for comparing conditions** is Jensen–Shannon (JS) divergence in bits between the forecast’s normalized distribution and the target checkpoint’s directly measured distribution at that same history. The manipulation is the language describing the roller or framing the prediction. The reference is the checkpoint’s response to an unchanged direct-generation prompt. The forecast logits measure the model’s propensity to answer with each face. A separate verbal assay asks what probabilities the model says it would assign. A free ten-roll sequence measures what it actually chooses under that forecast prompt.

**Deliverable.** Implement, freeze and test the protocol below in a fresh experiment in [chimpanzity/spar-coin-self-signature](https://github.com/chimpanzity/spar-coin-self-signature). Follow the repository’s approval process for paid collection and publishing. The design choices below are prospective defaults for this run. Dataset counts, thresholds and examples in this handoff are not experimental findings.

Append those three, then append the first four of all six faces ranked by `spar-dice-v1|restart|d1,d2,d3|candidate`. Ties in these rankings use numeric face order. This builds 16 ten-roll paths. Keep the prefixes for **k = 4 through 10**. There are 28 development and 84 confirmatory histories, in disjoint opening-triple families. Build the smaller scaffold/replication bank from confirmatory ranks 5–8 (4 families, 28 histories). Sample and analyze by family whenever several rows share a path.

## 5. Collect the distributions at the right decision

1. **Direct reference G(t,h).** Feed the unmodified G prompt to the target. For k = 1, take the first assistant distribution. For k > 1, use the incremental generation route to force the canonical face, separator, face token sequence for h and then **one trailing face separator**. Read the distribution immediately after that separator, before the next face. In the current engine, `history_ids(eng, faces)` constructs the interleaved history without a trailing separator. Add the separately validated separator for nonempty histories. `forced_dists(..., method="incremental", at=[n])` returns the distribution after consuming n forced tokens. For a validated single-token digit/space pattern n is 2 × len(h). Cache identical (checkpoint, G, h) rows. Score the reference even when h diverges from the target’s free greedy trajectory.
2. **Forecast F(p,word,scaffold,h).** Show h in the **user** turn of T1/T2, start a fresh assistant response and score its **first answer decision**. Use the native assistant turn template and empty forced assistant history. The digits shown to the forecaster belong in the user text only. Do not accidentally score “what follows a space-separated assistant trajectory” in both arms. If the unconstrained greedy answer begins with prose, keep it as an observed format failure; the full-vocabulary logits at the frozen answer boundary remain available. Do not scan forward until a convenient digit appears.
3. **Token validity.** Confirm by encoding, decoding and contextual tests that six distinct token IDs represent the six legal answers at each actual boundary. Scan vocabulary for newline/leading-space variants as in the archival preflight. Record IDs, separator and special tokens. If a variant decodes to the same legal answer under the frozen one-digit grammar, run the archive’s alternate-token check and record its maximum contribution. Halt the affected assay if the archive’s preflight fails or six comparable candidates cannot be scored. A revised answer grammar or a common prefill is a separately versioned assay for both models. Apply equivalent checks to A/B and any rotated fact labels.
4. **Raw and conditional scores.** From the untempered full-vocabulary fp32 log-softmax, save natural-log probabilities `l[1..6]` in face order. Compute `log_mass = logsumexp(l)`, `mass = exp(log_mass)`, `log_q[i] = l[i] - log_mass` and `q[i] = exp(log_q[i])`. Save all five quantities and the full-vocabulary top token. The six raw probabilities may sum to much less than one. Greedy generation selects the argmax; it does not turn the measured logits into a one-hot target. Keep full-precision scores for analysis and round only for display.
5. **No target leakage.** In the descriptor-only arm, collect F once with no checkpoint named in the prompt. Join that single vector offline to the direct references for Qwen and Mistral for exactly the same h. For named-target prompts, collect a genuinely different F for each name. A target name must not change the prefix, original instruction, response grammar or scorer. Blind the target-source metadata of natural histories to the forecasting model.

## 6. Preregister the comparisons

For two face-normalized vectors q and g define m = (q + g)/2. Compute **D = [KL(q‖m) + KL(g‖m)] / 2**, using base-2 logarithms in KL and the usual zero-mass convention. D ranges from 0 to 1 bit. A smaller value means a closer forecast. If using `scipy.spatial.distance.jensenshannon(..., base=2)`, **square** its return value. Unit-test an identical pair (0 bits), disjoint point masses (1 bit) and symmetry. Use stable arithmetic on the stored vectors. Keep the log-softmax in natural-log units as above.

For the primary arm, `neutral` means T1 plain *a shape*. In comparisons involving another scaffold, template or noun use the corresponding within-condition neutral.

| Quantity | Compute at each matched history | What a positive value means |
|---|---|---|
| Cue gain for target t | `gain(p,t,w) = D(F_neutral,G_t) − D(F_w,G_t)` | The cued forecast is closer to target t than its own neutral forecast is. |
| Selective own gain | `S(p,w) = gain(p,p,w) − gain(p,other,w)` | This cue improves relative alignment more for the forecaster’s own policy. Inspect absolute own gain alongside it. |
| Independent association contrast | `a = A(p,left) − A(p,right)` | The independently measured association favors the left word. |
| Directional association test | `sign(a) × [S(p,left) − S(p,right)]` | The more self-associated word produces greater selective own gain. Exact association ties contribute zero; report them. |
| Own improvement | Take `gain(p,p,w)` for the independently more self-associated member of the pair; on a tie average both gains. | The favored word actually improves own prediction. Selectivity can otherwise arise solely from worse predictions of the other model. |

**Primary summaries.** Use T1 plain, the six frozen confirmatory pairs, and the 84 confirmatory histories. Average histories within each opening-triple family, give the 12 families equal weight, average pairs equally, and report each checkpoint separately. Give both checkpoints equal weight in the joint summary. Report the directional association test and the accompanying own-improvement endpoint, each in bits, along with each pair’s signed contributions and association scores. A pooled positive value driven entirely by one checkpoint is a checkpoint-specific finding. A stable but flat association probe also limits what this experiment can say. Show development pairs, development paths, the longer neutral, T2 and natural paths separately. T2 shares four path families with T1; it tests wording robustness.

**Cross-check against an informed outsider.** For each named target t, display the full 2 × 2 matrix of distances for forecaster p × named target t at identical h. Compare improvement from “a language model” to the explicit name for the owner and the outsider. Also compare their absolute named-target distances for the same t. Explicit identical-checkpoint wording and an owner’s name may behave differently. Larger owner improvement plus closer absolute forecasting is stronger evidence than a shift induced by the name in both forecasters. In the adjective arm also show, for each target and word, how the *other* forecaster’s gain compares with the owner’s gain. This exposes generally helpful wording.

**Worked scoring fixture.** In face order 1–6, suppose G for the owner is `[.15,.01,.60,.22,.01,.01]` and G for the other is `[.50,.01,.30,.17,.01,.01]` after `5 2 6`. A neutral forecast of `[.33,.01,.33,.31,.01,.01]` and a blue forecast of `[.16,.01,.57,.24,.01,.01]` put the same 3% on already-used faces. Yet the cue improves owner JS by 0.05847 bits and worsens other-target JS by 0.07327 bits. Selective own gain is +0.13173 bits. Use these illustrative vectors as a unit test with tolerance 0.00002 bits. Blue’s association with SELF must still come from the independent task.

**Scaffold effect.** Within each of the seven descriptions, compute D under physical imagery, textual simulation and the neutral preamble for the same target and h. Report both D(plain) − D(scaffold) and D(neutral preamble) − D(scaffold). For each cue, also subtract its gain under plain wording from its gain under each scaffold, using the matching *a shape* control in each case. This estimates how much imagining the roller changes the cue’s effect. For the cued-generation control compare the six facewise shifts from neutral during direct generation with the corresponding shifts during forecasting on the same h. Report both sets of shifts.

**Other prespecified readouts.** Show legal face mass, proportion of full-vocabulary greedy tokens that are faces, JS, facewise probability residuals and top-face agreement. For rolls 2–6, show both the total forecast mass on unused faces and the target/forecast distributions *within* the unused set. A final unused face has probability one under this conditional measure. For roll 7, display the whole six-face restart distribution, and for rolls 8–10 use the within-second-block history in the repeat diagnostic. Use the full six-face vector for every primary score. Include a uniform baseline and a simple “uniform over faces unused in the current block of six” baseline (reset at roll 7, fall back to uniform if exhausted). Also report the equally weighted mixture of the two direct policies as a descriptive common-policy reference.

**Uncertainty and interpretation.** For the two primary summaries, give a 95% percentile interval over 10,000 two-way bootstrap draws with NumPy PCG64 seed 241124. Resample opening-triple families and adjective pairs separately with replacement; use the same drawn indices across model, target and condition cells. Report leave-one-pair-out and leave-one-family-out ranges. These intervals describe sensitivity to the measured cues and histories under that resampling choice. Six pairs and two fixed checkpoints do not support a population estimate for all adjectives or model families. Deterministic reruns, six faces and adjacent positions are not independent subjects. For small extension panels report paired differences and cell sizes rather than ranking dozens of exploratory winners.

| If the run shows… | Record this conclusion |
|---|---|
| A cue helps both targets or both forecasters about equally | The cue steers dice forecasts, with little evidence of model-specific behavioral identification. |
| Selective gain is positive but absolute own accuracy fails to improve | The contrast can be explained by deterioration against the other target. |
| Association predicts selective gain and positive own improvement on held-out data; the effect survives paraphrase, incidental-word and outsider comparisons | Evidence for **cue-facilitated, self-specific behavioral prediction** in these checkpoints and conditions.
