## Design

2 x 2 x 2 factorial per judge:
- Source identity: SELF vs OTHER
- Actual architecture: batch vs online (of the source trajectory)
- Stated architecture: told-batch vs told-online (what the judge is told)

Each unique trajectory presented twice in fresh stateless calls, once per
stated-architecture condition. Trajectory identity constant across the two
presentations; only the verbal description of production regime changes.

- 10 trials per cell x 8 cells = 80 trials/judge x 3 judges = **240 total**

## Stated-architecture sentences

**told-batch**:
> This sequence was generated by an LLM in a single call that simulated all 50 fair-coin flips at once.

**told-online**:
> This sequence was generated by an LLM across 50 separate calls that simulated one fair-coin flip per call, with the complete preceding flip history provided on each call.

## Interpretation caveats

- 10 trials per cell; accuracy granularity within a cell is 0.10.
- A positive self-specific provenance effect is the key SPAR pattern; a
  generic congruence effect is not evidence for a behavioral self-model.
- Do not describe positive results as self-awareness, consciousness, or introspection.
- Baselines above (source-model classifier and architecture-conditioned feature
  baseline) provide feature-based upper bounds against which to weigh judge behavior.
